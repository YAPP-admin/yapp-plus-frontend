- build·브라우저 화면·iPhone 설치/미설치·VoiceOver는 제품 구현 전이므로 미실행이다.
- 이후 사용자가 1단계 커밋·다음 단계 진행 및 이슈 생성·main 병합을 승인했다.

- 1단계 문서 커밋은 `037f96cf`, main 병합 커밋은 `7c0cd07d`다. 충돌 없이 병합했고 브랜치를 유지했다.
- 지정된 카카오 HTTPS 좌표 URL을 앱 스킴으로 변환하고 실행 실패 시 원본 URL을 연다.
  일반 외부 링크는 원래 동작을 유지하며 최종 실패만 Alert로 안내한다.

  구현 후 지도 실행 테스트 35개가 새 실행으로 통과했다.
- 첫 check는 새 코드의 중괄호 규칙 4건으로 실패해 수정했다. 최종 `node --run check`는 통과했다.
  format 및 모바일 lint·typecheck·26개 파일의 테스트 373개는 새 실행이다.

## 3단계 — 홈 카드와 웹 지도 링크

- 사용자의 2단계 리뷰 후 구현 시작 승인으로 웹 작업을 진행했다.
- PR 크기 제한에 따라 사용자 승인으로 명세·모바일을 `13ad337b`에 커밋하고
  `DongjaJ/home-session-map-web` 브랜치를 생성했다. 기존 브랜치 이름은 유지했고 push·PR은 생성하지 않았다.
- 웹 PR의 base는 `DongjaJ/dongjaj/keep-current-implementation`으로 분리한다.
- 한국 날짜 경계·제목 접미사·누락 장소·팀 장소·좌표 링크 및 키보드 접근을 테스트했다.
  기존 출석 안내·팀 사진 처리·결과 모달·로딩 테스트도 유지했다.
- 최초 회귀 테스트는 구현 전 실패했다. 구현 후 관련 테스트와 typecheck가 통과했다.
  check에서 발견된 중첩 조건식·빈 문자열 fallback 린트 오류를 수정했다.
- Playwright와 로컬 개발 서버에서 모의 세션을 주입해 실제 홈을 확인했다.
  320px 긴 장소명은 줄바꿈되며 가로 넘침이 없고, 링크 높이 44px·focus-visible 2px 외곽선·좌표 순서를 확인했다.
  390px 다크 모드의 정규 버튼 대비를 테마 색상 토큰으로 보정했다.
- 화면 증거: `.context/home-map-320.png`, `.context/home-map-390-dark.png`.
- iPhone 설치/미설치·앱 복귀와 실제 VoiceOver는 미실행이다. T016은 수용 검증이 남아 완료로 표시하지 않는다.
- T017의 사용자 리뷰도 대기 중이다. API·브리지 공개 타입·의존성 변경은 없다.

  나머지 lint 6개·typecheck 6개·test 4개 작업은 Turbo 캐시 재사용이다.
- 최종 `node --run build` 통과: 웹은 새 실행, admin·storybook은 캐시 재사용이다.
  웹 번들의 500kB 초과 경고가 남아 있으며 빌드 실패는 아니다.
- 모바일·명세 PR은 origin/main 대비 +584/-2(586줄), 웹 PR은 모바일 브랜치 대비 새 파일을 포함해
  600줄 미만이다. 각 PR이 800줄 미만이며 웹은 아직 커밋하지 않았다.
- 3단계 리뷰 반영: 장소·제목 계산을 const 기반 조건식으로 정리했다. Chrome에 모의 세션 개발 화면을 열어 사용자 확인을 준비했다.

- 후속 리뷰에서 좌표 마커 대신 도로명 주소 검색으로 전환했다. 웹은 주소와 좌표를 함께 검증하고, 셸은 q·p를 재검증해 앱 검색 또는 웹 주소 검색을 연다. 기존 좌표 링크 호환 처리는 유지한다.
- 주소 검색 전환 후 check 통과: 웹 782개·모바일 397개 테스트와 양쪽 lint·typecheck는 새 실행,
  나머지 패키지는 Turbo 캐시 재사용이다. 모바일 외부 탐색 59개 테스트에 검색 성공·웹 대체·최종 실패·주소 인코딩·중복 파라미터·잘못된 origin 사례를 포함했다.

  iPhone 실제 검색 결과·앱 복귀는 미검증이며 신규 설정·의존성은 없다.

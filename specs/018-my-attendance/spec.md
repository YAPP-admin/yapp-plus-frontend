# 기능 명세: 마이페이지·출석 내역 연동

**브랜치**: `DongjaJ/my-page-api` (base: `DongjaJ/my-page-attendance-api-plan`)

**작성일**: 2026-11-07

**상태**: 3단계 코드·자동 검증 완료·화면 검증 및 리뷰 대기

**관련 이슈**: [#352](https://github.com/YAPP-admin/yapp-plus-frontend/issues/352)

**요청**: 안드로이드와 같은 지원 범위로 먼저 연동하고 각 단계 리뷰 후 진행한다.

## 사용자 시나리오와 검증

### US1 — 내 프로필과 출결 현황을 확인한다 (P1)

회원은 마이페이지에서 자신의 이름과 확정 출결 점수·횟수를 확인한다.
지원되지 않는 정보를 실제 값으로 오인하지 않는 것이 우선이다.

**독립 검증**: 로그인 후 마이페이지를 열어 계정 이름, 점수와 출석·지각·결석 횟수를 확인한다.

1. 이름이 있는 계정으로 로그인하거나 가입하면 자신의 이름이 표시되고 앱 재시작 후에도 유지된다.
2. 이름이 없는 기존 세션이나 구버전 앱에서는 이름을 `—`로 표시하며 다시 로그인하도록 강제하지 않는다.
3. 회원 구분·기수·직군·지각 면제권은 `—`로 표시한다. 지각 면제권을 조퇴나 구제로 바꾸지 않는다.
4. 출결 조회에 성공하면 받은 점수·횟수를 표시한다. 0은 실제 0으로 표시한다.
5. 조회 대상이 아니거나 현재 기수가 없으면 점수·횟수를 `—`로 표시한다.
6. 최초 조회 실패 시 오류와 재시도를 제공하며 프로필·출석 내역 이동·출석 규칙은 사용할 수 있다.

### US2 — 전체 출석 내역을 이어서 확인한다 (P2)

회원은 최신 세션부터 스크롤하며 자신의 출석 결과와 세션 현황을 확인한다.
한 번에 받은 목록만으로 전체 출결을 판단하지 않는 것이 목적이다.

**독립 검증**: 여러 페이지의 내역을 준비하고 마지막 페이지까지 내려 중복·누락 없이 확인한다.

1. 전체·남은 세션 수는 조회 요약으로 표시하고 진행률은 `—`로 표시한다.
2. 목록 끝에 도달하면 다음 내역을 자동으로 추가한다. 마지막 페이지에서는 요청을 멈춘다.
3. 출석·지각·결석·조퇴·지각·조퇴·공결 및 미확정 결과를 구분한다.
4. 미확정 결과는 운영진 판단에 따라 검토중·반려·미제출·미선택·미확정으로 표시한다.
5. 추가 조회 실패 시 기존 내역을 유지하고 재시도를 제공한다. 오류를 빈 내역으로 표시하지 않는다.
6. 모든 내역이 비어 있고 다음 페이지도 없으면 `아직 출석 내역이 없어요`를 표시한다.
7. 전체 확정 결석 횟수가 9회면 경고하지 않고 10회 이상이면 기존 경고 문구를 표시한다.
8. 직접 출석 내역에 진입해도 경고를 판단하며 뒤로가기로 MY에 돌아올 수 있다.

### US3 — 계정 전환과 조회 실패 후 안전하게 복구한다 (P1)

회원은 로그아웃·다른 계정 로그인 이후 이전 회원의 이름과 출석 기록을 보지 않는다.

**독립 검증**: 지연된 조회·세션 갱신 도중 계정을 바꾸고 이전 응답이 현재 화면에 반영되지 않는지 확인한다.

1. 이름이 없는 다른 계정으로 로그인해도 이전 계정의 이름을 이어 쓰지 않는다.
2. 같은 계정의 재조회 실패는 이전 데이터와 실패 안내를 함께 표시한다.
3. 같은 로그인 세션의 토큰 갱신은 이름을 유지하며 계정 변경은 이전 데이터와 함께 정리한다.
4. 숨겨진 화면에서는 무한 스크롤 요청을 시작하지 않으며 복귀·재연결은 기존 조회 정책을 따른다.

### 경계 사례

- 이름이 공백·잘못된 값이면 이름만 없는 것으로 처리하고 유효한 로그인 자격은 보존한다.
- 잘못된 출결 응답은 오류이며 누락 필드·음수 횟수를 임의의 0으로 채우지 않는다.
- 점수 조회 실패가 출석 목록을 가리지 않으며 현재 결석 횟수를 확인할 수 없으면 경고를 추정하지 않는다.

## 요구사항

### 기능 요구사항

- **FR-001**: 이름을 로그인 세션에 연결해 보관하고 갱신·재시작 시 유지하며 세션 종료 시 정리한다.
- **FR-002**: 이름 없는 기존 세션·구버전 앱을 허용하고 이전 회원의 이름을 보충하지 않는다.
- **FR-003**: 미지원 회원 구분·기수·직군·지각 면제권·진행률은 `—`로 표시한다.
- **FR-004**: 확정 점수·출석·지각·결석 횟수를 표시하고 조회 대상 아님을 오류와 구분한다.
- **FR-005**: 최신순 내역의 무한 스크롤과 추가 조회 재시도를 제공한다.
- **FR-006**: 출결과 운영진 판단 상태를 안드로이드와 동일하게 표시한다.
- **FR-007**: 전체·남은 세션 수는 요약을 사용하며 전체 확정 결석 10회 이상만 경고한다.
- **FR-008**: 로딩·최초 오류·추가 조회 오류·재조회 오류·빈 결과를 구분한다.
- **FR-009**: 기존 인증 복구·계정 격리를 유지하고 MY 탐색·뒤로가기·숨김 화면 수명을 지킨다.
- **FR-010**: 고정 샘플 데이터를 실제 화면에서 제거하고 개발용 상태는 개발·테스트 환경에서만 제공한다.

### 주요 개체

- **회원 표시 정보**: 세션에 속한 선택적 이름과 미지원 프로필 항목.
- **출결 점수**: 현재 활동 기수의 확정 점수와 출결 횟수. 목록 부분 집계와 구분한다.
- **출석 내역 페이지**: 세션별 결과, 세션 진행 요약, 다음 페이지 표시자.

## 성공 기준

- **SC-001**: 정상·0값·조회 대상 아님에서 표시 정보가 제공 데이터와 일치하고 고정 샘플이 없다.
- **SC-002**: 3페이지 이상 내역에서 모든 세션을 한 번씩 확인하고 마지막 페이지 이후 추가 조회가 없다.
- **SC-003**: 추가 조회 실패 후 기존 목록을 잃지 않고 재시도로 이어서 확인할 수 있다.
- **SC-004**: 재시작·갱신·계정 전환 검증에서 이름과 출결의 계정 혼합이 발생하지 않는다.
- **SC-005**: 직접 진입·MY 복귀·키보드·터치로 주요 동작을 완료하고 상태 안내를 읽을 수 있다.

## 가정과 범위

- 기준은 [Hand off 마이페이지](https://www.figma.com/design/LUFGoDnVmwJT43QhecBI8x/YAPP-?node-id=222-40302)와 사용자 승인한 안드로이드 지원 범위다. 과거 Wireframe의 구제 칸은 적용하지 않는다.
- 프로필·지각 면제권 보완은 사용자가 백엔드에 요청했으며 계약 확정 후 별도 작업으로 처리한다.
- 진행률 계산·백엔드 문의, 출석 제출·사전 보고, 관리자 화면, 새 의존성은 범위 밖이다.
- 기존 로그인 사용자는 이름 정보가 없으면 다음 정상 로그인·가입까지 `—`일 수 있다.
- 자동화 회귀 테스트와 실제 환경 검증을 요구하며 서로 대체한 것으로 보고하지 않는다.

# 홈 표시와 외부 지도 탐색 계약

## 웹 링크

`https://m.map.kakao.com/scheme/search?q={인코딩한 도로명주소}&p={latitude},{longitude}`를 `href`로 가진 일반 링크를 사용한다.
`target`은 지정하지 않아 기존 WebView 외부 탐색 처리로 전달한다. 별도 브리지 메서드는 없다.
아이콘과 장소명을 같은 링크 안에 넣고 접근성 이름에 장소명과 “카카오맵에서 보기”를 포함한다.
장식 아이콘은 `aria-hidden` 처리하고 링크는 포커스·키보드 기본 동작을 유지한다.
14px 핀의 시각 크기와 별개로 터치 영역을 최소 44px 높이로 확보하고 제목과 겹치지 않게 한다.
긴 장소명은 줄바꿈한다. 주소 또는 좌표가 없으면 동일 장소 안내를 비상호작용 요소로 표시한다.

## 네이티브 처리

- 앱의 trusted origin 탐색 판정은 기존 위치에 남긴다.
- 검색 변환 대상은 HTTPS, 정확한 `m.map.kakao.com` origin과 `/scheme/search` 경로이며 q·p가 있는 URL이다.
- q는 공백 제거 후 비어 있지 않아야 한다. 좌표 값은 저장·웹 링크 생성 단계에서 검증하며 셸에서 범위를 다시 검사하지 않는다.
- 유효하면 `kakaomap://search?q={인코딩한 주소}&p={위도},{경도}`로 검색한다.
  p는 검색 중심이며 특정 마커나 단일 검색 결과를 보장하지 않는다.
- 앱 실행 실패 시 `https://map.kakao.com/link/search/{인코딩한 주소}`를 연다.
- 기존 `map.kakao.com/link/map/{위도},{경도}`의 좌표 마커 변환·원본 URL 복구는 호환성을 위해 유지한다.
- 대상이 아니거나 주소·좌표 파라미터가 없는 URL은 앱 스킴으로 바꾸지 않고 기존 외부 URL로 처리한다.
- 기존 외부 URL 동작을 유지하되 최종 실패를 처리한다. 원문 오류 대신
  “링크를 열지 못했어요. 잠시 후 다시 시도해 주세요.”를 native Alert로 안내한다.
- 반복 호출은 같은 URL이 처리 중일 때만 합친다. 성공 후 다시 누르면 새 시도로 처리한다.

## 카드 표시

- 장소와 제목 사이는 기존 토큰을 사용하고, 카드 padding 18px 20px·모서리 12px를 유지한다.
- 제목은 한국 날짜의 오늘/이번 주를 구분한다. 정규 카드만 별도 시작 시간 줄을 제거한다.
- 달력 강조 우선순위는 출석 완료 → 오늘 → 세션 예정일 → 일반 날짜다.
- 완료 배지·“출석” 문구는 유지하고, 예정일은 브랜드색으로 표시한다.
- 7개 날짜 열의 양끝과 사이에 점선 구분선을 둔다. 정규 달력은 일반 54px·완료 58px를
  최소 높이로 사용하며 요일과 날짜 간격은 일반 4px·완료 2px를 기준으로 한다.
- 정규 출석 버튼은 Android `HomeAttendance`·`HomeSecondary`·`HomeSecondarySmall`을
  기존 SEED 토큰·컴포넌트로 대응한다. 활성 버튼은 최소 44px 터치 높이를 유지한다.
- 상태별 문구·활성 조건·출석 전 20분 안내·마감 안내는 변경하지 않는다.
- 팀 사진 정보·썸네일·검토 UI·제출 및 결과 모달 연결은 변경하지 않는다.
- 로딩·빈 상태·오류와 세션 없음의 기존 달력 동작도 유지한다.

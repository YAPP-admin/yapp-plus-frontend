# 웹 화면 배치·탐색 계약

## 높이와 스크롤

- 상단 safe-area는 ActivityScreen/AppScreen이 소유한다. 자식은 제공된 콘텐츠 높이를 사용하고 다시 100dvh를 요구하지 않는다.
- 프레임은 헤더·본문·선택적 하단 액션을 합성한다. 헤더·액션은 축소하지 않고 본문은 min-height: 0으로 남은 공간에서 스크롤한다.
- 액션은 좌우 16px, 상하 기본 12px이다. 하단 안전 여백은 액션·탭·본문 끝 중 실제 최하단 소유자 한 곳만 추가한다.
- 공지 확인은 액션 슬롯으로 이동하지 않고 본문 끝에 둔다.
- 상태바 observer에는 활성 본문의 root와 시작점을 연결한다. 탭 전환 시 관찰 대상만 교체하고 DOM은 유지한다.
- 기존 헤더·최대 폭·메뉴 순서·회원 탈퇴 위치는 유지한다.

## 가입 가시 영역

앱 콘텐츠 영역과 visual viewport를 같은 layout 좌표계로 환산한 뒤 교집합을 구한다.
높이는 `max(0, min(appBottom, viewportBottom) - max(appTop, viewportTop))`이다.
이미 줄어든 앱 높이에서 키보드 높이를 다시 빼지 않는다. 고정 키보드 높이·기종 상수는 쓰지 않는다.

- `VisualViewport` 미지원 시 기본 콘텐츠 높이와 스크롤 접근성을 유지한다.
- scale이 기본 배율이 아닌 경우 키보드 전용 보정을 적용하지 않고 확대·패닝을 허용한다.
- resize·scroll 구독과 예약 작업은 활성 상태에 맞춰 연결·해제한다.
- 키보드에 가려진 기기 하단 inset을 중복 빈 공간으로 남기지 않으며 키보드가 닫히면 복구한다.

## 가입 탐색

- Signup Activity에 선택적 step만 추가한다. 기본값은 name이고 잘못된 단계 입력은 name으로 정규화한다.
- 이름 제출은 phone step 추가, phone 뒤로가기는 step pop, name 뒤로가기는 기존 로그인 복귀다.
- 새로고침·직접 진입 시 phone 이력이 있더라도 입력 초안이 없으면 name부터 시작한다.
- 서버 이름 오류는 기존 name 단계로 복귀하고 포커스한다. 폼 인스턴스와 다른 오류를 유지한다.
- 브라우저·Android 시스템 뒤로가기와 헤더 뒤로가기가 같은 단계 규칙을 따른다.
- 서버 API, native 인증 저장, safe-area 브리지 메시지 계약은 변경하지 않는다.

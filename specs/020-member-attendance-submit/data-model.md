# 데이터와 상태

- 출석 대상: 현재 주 응답의 sessionId(양의 안전한 정수), 날짜·시작 시각, attendanceStatus. 서버 상태를 그대로 사용한다.
- 코드 입력: 메모리 문자열 4자리 ASCII 숫자. 서버 요청에서는 정수로 변환한다.
- 출석 응답: verified가 true이고 checkedInAt이 유효한 시각일 때 성공이다.
- 출석 완료 표시: 성공 mutation의 대상 ID를 사용한다. 계정 범위(userId·sessionId)와 출석 대상 sessionId에 종속한다. 계정 변경·앱 재시작에 제거한다. 토큰 버전만 바뀐 경우 같은 계정이다.
- 보고 입력: LATE / EARLY_LEAVE / ABSENT와 선택적 reason. 전송 전 trim하며 UTF-16 30자 이내다.
- 보고 응답: 양의 안전한 정수 sessionId와 유효한 submittedAt. 제출 시각을 클라이언트 현재 시각으로 대체하지 않는다.
- 화면 상태: 입력 → 제출 중 → 서버 확인 후 완료 또는 수정 가능한 오류. 중복 제출을 차단하고 화면 이탈·계정 변경 후 결과로 탐색하지 않는다. 화면 이탈 뒤 같은 계정의 서버 성공은 보존한다.
- 요청이 처리되었는지 알 수 없는 네트워크 오류는 성공도 실패 확정도 아니다. 자동 재제출을 하지 않고 사용자에게 결과 확인 불가와 수동 재시도를 안내한다.

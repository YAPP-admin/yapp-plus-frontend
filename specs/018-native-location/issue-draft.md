# feature: 출석용 앱 위치 수집과 웹 브리지 제공

담당자: `DongjaJ` · 추가 라벨·milestone 없음 · 사용자 승인 후 [#353](https://github.com/YAPP-admin/yapp-plus-frontend/issues/353)으로 생성 완료.
GitHub 생성 시 제목과 이 안내는 제외하고 아래 본문만 사용한다.

## 작업 배경

회원 출석을 위해 앱에서 수집한 위치를 웹에 전달할 기반이 필요하다.
현재 브리지는 인증과 safe-area만 제공하며 실서비스 출석 제출은 비활성 상태다.
이번 작업은 iOS·Android의 단발 위치 수집·권한 조회·설정 열기까지만 제공한다.

## 작업 내용

- [ ] 사용자 요청으로 위치를 한 번 수집하고 좌표·정확도·측정 시각·정밀 권한 수준을 웹에 전달한다.
- [ ] 팝업 없는 권한 조회, 권한 거부·재요청 불가·서비스 꺼짐·timeout을 구분한다.
- [ ] 사용자 동작으로 앱 설정을 열고 다음 요청에서 변경된 권한을 확인한다.
- [ ] 수집 종료와 늦은 응답·중복 호출을 처리하고 위치를 저장하거나 로그로 남기지 않는다.
- [ ] 일반 브라우저의 위치 호출 차단와 개발 도구의 프로덕션 접근 차단을 검증한다.
- [ ] 새 네이티브 바이너리의 런타임을 분리하고 iOS·Android에서 검증한다.

## 완료 조건

- [ ] 자동 테스트·check·build·expo:doctor 결과와 캐시 사용 여부가 기록되어 있다.
- [ ] iOS·Android 실기기에서 정상 수신·권한 복구·오류·수집 정리를 확인했다.
- [ ] 실서비스 출석 버튼을 활성화하지 않고 위치를 출석 서버에 제출하지 않는다.
- [ ] 기존 런타임에 호환되지 않는 OTA를 배포하지 않으며 복구 방법이 기록되어 있다.

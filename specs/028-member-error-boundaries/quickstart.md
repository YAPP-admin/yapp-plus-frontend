# 검증 안내

이 문서는 구현 후 실행할 시나리오다. 아래 항목을 이번 문서 작업에서 실행했다고 해석하지 않는다.
전제: 저장소의 고정 Node·pnpm과 의존성이 준비되어 있고 MSW/브리지 대역으로 오류 응답과 지연을 제어한다.
실제 인증 정보·토큰·응답 개인정보를 로그나 스크린샷에 남기지 않는다.

## 명령

저장소 루트에서 실행한다. `mise`가 작업 디렉터리를 신뢰하는지와 Node 24.20.0·pnpm 12.3.4를 먼저 확인한다.
예상치 못한 신뢰·설치 문제로 고정 버전 대신 다른 버전을 사용하지 않는다.

```sh
pnpm --filter @yapp-plus/web test -- src/shared/ui/error-state.test.tsx src/shared/ui/local-error-boundary.test.tsx
pnpm --filter @yapp-plus/web test -- stackflow/src/query-recovery.test.tsx stackflow/src/account-boundary.test.tsx
node --run check
node --run build
node --run dev:web
```

새 파일을 대상으로 하는 첫 명령은 해당 단계에서 파일 생성 후 실행한다. 각 단계는 변경에 가까운 테스트를
우선 실행하고 품질 게이트를 완료한다. 같은 결과를 반복 확인하려고 불필요하게 전체 실행을 늘리지 않는다.

| --- | -------------------------------------------------- | --------------------------------------------------- | -------------------------- |
| Q01 | 최초 조회500 → 다시 시도200                        | Local 오류 → 로딩 → 콘텐츠                          | Local+대표 일정 테스트     |
| Q02 | 조회200 → 재조회500                                | 기존 콘텐츠 제거, 실패 영역만 오류                  | 일정·프로필 페이지         |
| Q03 | 성공 cache 오류 → reset → 다시500/200              | 요청 시작, 로딩 표시, 반복 throw 루프 없음          | Local/query-recovery       |
| Q04 | 오류 화면 숨김 → 복귀, 정상 화면 숨김 → 복귀       | 오류 fallback 유지, 정상 DOM 유지                   | Stackflow query-recovery   |

| Q12 | 입력 중 일반 재조회 실패 → 복구                    | 셸 유지, 경계 내부 입력 초기화                      | 출석·보고 시트             |
| Q13 | 제출 일반 실패·공지 낙관적 실패                    | 입력 유지·기존 롤백, 로그인 이동 없음               | Mutation 인접 테스트       |
| Q14 | 제출 성공 → invalidate 조회 실패                   | 제출 완료 유지, 자동 재제출·완료 callback 소실 없음 | 코드 출석·출결보고         |
| Q15 | presign/최종 제출401, 외부 PUT403                  | 앞의 두 경우 Login, PUT은 업로드 실패               | 사진 제출                  |
| Q16 | 알림 AUTH_REQUIRED/UNSUPPORTED/PERMISSION_REQUIRED | 인증만 Login, 나머지는 기존 전용 안내               | 알림 설정                  |
| Q17 | App 최종 렌더링 오류                               | Query/라우터 없이 새로고침·홈 링크 동작             | App 경계                   |
| Q18 | page/section, 긴 제목, 320px 화면, 키보드          | 가로 넘침 없음, 액션 조작·오류 안내 가능            | UI 테스트+브라우저         |

## 실제 화면 확인

- 웹: 개발 미리보기·일정·공지·홈·MY·출석 시트·알림에서 교체 범위와 탐색 유지 확인.
- WebView: 인증 이동 중 뒤 화면·Portal·시트가 남지 않는지, 안전 영역·뒤로가기 확인.
- 접근성: 의미 있는 제목, 오류 알림, 재시도에 키보드 접근, 장식 그림 중복 읽기 없음,
  재시도 후 콘텐츠에 접근 가능한 포커스 흐름과 터치 영역 확인.
- 자동 대역으로 검증한 인증 흐름과 실제 서버·기기 성공은 구분한다. 기기·계정이 없으면 미실행으로 남긴다.
- 각 결과에 command·exit code·신규 실행/Turbo 캐시·실패·미실행·증거 경로를 기록한다.

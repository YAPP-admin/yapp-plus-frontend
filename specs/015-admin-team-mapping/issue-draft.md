이 파일은 생성 당시 본문 초안과 로컬 작업 기록이다.

## 작업 배경

회원 관리에서 팀 구성과 미배정 현황을 확인하고 팀원 배정 입력을 검토할 화면이 필요합니다.
Figma와 사용자 인터뷰에 따라 개발·운영 모두 동일한 합성 예시를 제공하고 실제 저장·API 연동은 후속으로 분리합니다.

## 작업 내용

- [ ] 팀 빌딩 전·배정 중·확정됨 화면, 목록·분류·개수·상세를 제공합니다.
- [ ] 팀 생성 입력과 회원 검색·선택, 최소 팀원 유지 검증을 제공합니다.
- [ ] 상세 패널 변경 예정과 미배정 개별·일괄 대상 선택을 제공합니다.
- [ ] 초안 폐기 확인, 확정 요약·이력과 확정 후 팀원 전용 편집을 제공합니다.
- [ ] 모든 환경에서 동일한 예시 화면·입력과 비활성 최종 실행을 유지합니다.

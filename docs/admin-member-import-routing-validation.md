# 관리자 라우팅 PR 5 검증

- 확인일: 2026-10-11. 관련 이슈: [#54](https://github.com/YAPP-admin/yapp-plus-frontend/issues/54).
- 기준 커밋: PR 4 `ebd651f`. 브랜치: `DongjaJ/admin-members-import-routing`.
- 범위: `/members/import` 최소 화면, 회원 목록의 업로드 링크, 목록 복귀 링크.
- 파일 선택·파싱·미리보기·저장·API·인증은 포함하지 않는다.

## 경로와 탐색

- 업로드는 공통 관리자 셸 아래 별도 화면이며 회원 목록의 탭·검색·필터를 렌더링하지 않는다.
- 파일 라우트의 `members_`로 목록 부모의 중첩을 피하고 URL은 `/members/import`를 사용한다.
- 업로드 화면에서도 회원 관리 메뉴를 현재 메뉴로 표시한다.
- 업로드 진입과 명시적인 목록 복귀는 쿼리를 비운다. 브라우저 뒤로가기는 이전 회원 쿼리를 복원한다.
- 준비 중 안내와 실제로 이동하는 링크만 제공하며 effect나 라우터 이벤트 구독을 추가하지 않는다.

## 검증 결과

- `mise exec -- node --run check`: 포맷·lint·타입 검사·전체 테스트 통과.
- `mise exec -- node --run build`: 전체 빌드 통과.
- 관리자 테스트 8개 파일, 103개 통과. 직접 접근·화면 분리·쿼리 복원·키보드 이동·404 테스트 4개 추가.
- 프로덕션 서버 `/members/import`는 HTTP 200과 업로드 문서 제목을 반환하며 회원 검색 UI가 없다.
- `/members/import/missing`은 HTTP 404를 반환한다.
- Chrome에서 업로드 진입·새로고침·뒤로가기 필터 복원·명시적인 기본 목록 복귀를 확인했다.
- 375px·1280px에서 가로 넘침이 없으며 복귀 링크 높이 44px와 키보드 포커스 테두리 2px를 확인했다.
- 생성 라우트는 Vite로 갱신했다. 새 의존성은 없다.

# Pretendard 네이티브 폰트

- 버전: Pretendard **v1.3.9**
- [공식 원본](https://github.com/orioncactus/pretendard/blob/v1.3.9/packages/pretendard/dist/public/variable/PretendardVariable.ttf)
- 라이선스: 같은 디렉터리의 LICENSE
- 크기: 6,739,336바이트
- SHA-256: `3090ccde0442bb347aa7685d9ba8b17436a60682df6e8f92a9a670de14056e22`

Expo는 OTF와 TTF를 모두 지원하고 둘 다 제공될 때 OTF를 권장한다. 이 버전의 공식 가변 폰트는
TTF로 제공되므로 변환 없이 사용한다. 서버 콘텐츠와 사용자 이름에 필요한 글자가 누락되지
않도록 전체 글리프를 유지한다. 웹의 unicode-range 다이나믹 서브셋은 네이티브 로딩에 적용되지 않는다.

폰트와 LICENSE를 함께 갱신하고 apps/mobile/README.md의 검증 절차를 따른다.

- [x] 명세는 사용자 경험과 결과를 설명하고 기술적 저장 형식은 별도 문서에 둔다.

- [x] 제공되지 않은 사유와 사진 없음·실패를 구분한다.

- [x] 시작 전 결과는 사용자 선택에 따라 세션 시작 이후 홈 진입·복귀부터 안내한다.

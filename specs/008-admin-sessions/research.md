## 경계 확인

- `router.test.tsx`의 기존 직군 선택과 키보드 순서 기대값을 새 UI의 실제 행동에 맞게 갱신한다.
- 로그인·404는 관리자 셸 바깥이다. 공통 레이아웃 변경 후에도 유지한다.
- 현 API 패키지는 생성 기반 준비 단계다. 이번 모의 모델을 서버 API라고 문서화하지 않는다.
- SEED 고정 버전은 css 2.8.3·react 2.5.0이다. 최신 메이저 버전의 snippet을 그대로 복사하지 않는다.
- 모의 데이터는 실명·실제 출석 기록 없이 구성한다. 실패 재현을 위해 제품에 디버그 메뉴를 넣지 않는다.
- 제품 정책은 spec의 D1~D6로 확정했다. 컴포넌트별 공개 API·snippet의 고정 버전 호환성은 해당 구현 단계에서 확인한다.

## 수정 폼 반영

- 사용자 지시로 읽기 전용 정보 모달을 수정 폼으로 변경한다. 12단계를 폼 재사용·초기값과 저장 연결로 나누고 각각 리뷰받는다.
- 생성·수정의 필드와 검증이 같으므로 수정 구현 시 공통 폼으로 추출한다. 수정 서비스는 id·출석 집계를 보존한다.

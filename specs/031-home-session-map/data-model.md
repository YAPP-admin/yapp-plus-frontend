# 데이터와 수명

## 입력

기존 `CurrentWeekSessionDetailResponse`의 `type`, `name`, `date`, `startTime`, `attendanceStatus`,
`location`, `latitude`, `longitude`를 읽는다. 생성 타입과 응답 스키마를 직접 수정하지 않는다.

## 표시 변환

- 장소명: TEAM은 “팀별 자율 장소”; REGULAR은 `location.trim()` 또는 “장소 미정”.
- 제목: 이름 양끝 공백과 마지막 “세션” 한 번을 제거하고 정해진 제목을 붙인다.
  제거 결과가 비면 “오늘은 세션이 있어요” 또는 “이번 주는 세션이 있어요”로 표시한다.
- 오늘 여부: 기존 한국 날짜 유틸과 화면 재조회 수명을 사용한다. 새 자정 타이머를 추가하지 않는다.
- 지도 URL: 유한한 위도 -90~~90·경도 -180~~180이 모두 있으면 생성하고, 아니면 null이다.

## 실행 수명

iOS 외부 탐색은 앱 열기 성공으로 종료하거나, 실패 후 HTTPS 열기로 종료한다.
둘 다 실패하면 안내한다. 처리 중 같은 지도 링크의 중복 실행을 막고 완료 시 해제한다.
지도 목적지·오류를 영속 저장하지 않고 URL이나 원문 오류를 로그에 남기지 않는다.
계정·주간 Query·팀 결과 표시 이력은 기존 소유자가 유지한다.

# SEED 시간 휠 정착 상태 패치

#146(S01)의 확정 경합을 막기 위해 기존 SEED TimePicker UI를 유지하며 정착 상태를 노출합니다.
`onIndexChange`는 중간 항목도 전달하므로 최종 시간으로 사용하지 않습니다.

- `@seed-design/react-wheel-picker@1.1.1`에 선택적 `onSettlingChange`를 추가합니다.
  키보드·스크롤·휠·터치·마우스 드래그 시작 시 `true`, 기존 정착 처리에서 최종값을 전달한 뒤
  `false`를 알립니다. 값이 바뀌지 않은 조작도 정착 완료를 알립니다.
- `@seed-design/react@2.5.0`의 TimePicker는 컬럼별 상태를 합칩니다. 모든 컬럼이 정착해야
  `false`를 전달합니다. 기존 콜백과 시간 계산은 유지합니다.
- 관리자 일정 모달은 정착 중 확인 버튼을 비활성화합니다. 취소와 Escape는 계속 사용할 수
  있으며, 취소한 초안은 저장하지 않습니다. 날짜 선택은 영향을 받지 않습니다.

패치는 pnpm의 `patchedDependencies`로 고정합니다. 패키지에 배포된 소스, ESM/CJS와 타입을
함께 수정하므로 재설치에도 유지됩니다. 다른 소비자는 새 선택적 콜백을 사용하지 않아 기존
동작을 유지합니다. SEED 업그레이드 시 패치 충돌을 무시하지 않고 공식 정착 API 제공 여부와
회귀 테스트를 확인합니다. 공식 API로 같은 동작을 구현할 수 있으면 패치를 제거합니다.

관리자 실제 SEED 컴포넌트 테스트로 즉시 확정 차단, 최종값 저장, 여러 컬럼의 터치·취소,
변경 없는 정착과 모달 취소 후 재진입을 확인합니다. happy-dom 검증은 실제 모바일 관성과
스크린 리더 검증을 대체하지 않습니다. 실기기에서 빠른 휠 조작 후 확인, 동시 컬럼 조작,
관성 중 취소를 추가 확인해야 합니다.

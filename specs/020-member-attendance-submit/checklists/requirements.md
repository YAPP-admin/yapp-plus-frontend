# 요구사항 품질 점검

대상: [명세](../spec.md) · 확인일: 2026-11-17

- [x] 사용자 가치·범위 중심이며 명세에 구현 코드를 넣지 않았다.
- [x] 두 사용자 시나리오의 우선순위·독립 검증·성공 조건이 있다.
- [x] 성공 기준은 관찰·검증 가능하다.
- [x] 실패·중복·계정 전환·화면 이탈·접근성 경계를 명시했다.
- [x] 최초 Android 비교 기준과 이번 웹 보고 정책을 구분하고 다른 제품 기능을 제외했다.
- [x] 서버 정책과 화면의 임시 완료 상태를 구분했다.
- [x] 범위·의존성과 구현 전 승인 경계를 기록했다.
- [x] 미해결 제품 질문과 템플릿 자리표시자가 없다.
- [x] 사유 필수·세 유형의 시작 전 마감·일요일 전환·결석 규정과 감점 구분을 명시했다.
- [x] 뒤로가기 입력 보존·닫기 폐기·접수 불확실 시나리오가 있다.
- [x] 계획·계약·작업·검증 절차에 제출 직전 재조회 없음과 mutate 사용이 일치한다.
- [x] 네 단계와 사용자 리뷰 경계를 기록하고 실기기·실서버 검증을 별도로 분리했다.

문서 자체의 품질 검토이며 제품 구현·테스트 통과나 사용자 단계 리뷰 완료를 뜻하지 않는다.

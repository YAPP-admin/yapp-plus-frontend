# 요구사항 품질 점검

대상: [spec.md](../spec.md) · 작성일: 2026-11-20 · 범위: 1단계 문서 품질

- [x] 사용자 가치와 정규·팀 출석 흐름을 구분했다.
- [x] 사용자 시나리오에 우선순위와 독립 검증 기준이 있다.
- [x] 다섯 서버 상태·세션 없음·임시 유형 판별을 명시했다.
- [x] 조회 실패·취소·중복·직접 진입·계정/주차 변경을 포함했다.
- [x] 요구사항은 검증 가능하며 성공 기준과 작업 목록으로 이어진다.
- [x] 제출 전 미리보기와 제외한 제출 후 사진 조회를 구분했다.
- [x] 승인 팝업·FCM·반려 상세를 제외했다.
- [x] 회원용 조회 API 부재를 3단계 선행 조건으로 표시했다.
- [x] 가짜 엔드포인트·타입·멤버십 ID로 계약 공백을 메우지 않았다.
- [x] 단계별 사용자 리뷰와 구현·외부 변경 승인 범위를 구분했다.
- [x] 규칙 예외 없이 최소 변경·생성 계약·복구·검증을 계획했다.

문서 품질 점검과 아래 구현 준비 상태는 별개다.

- [ ] 사용자 1단계 리뷰 및 2단계 진행 확인.
- [ ] 회원용 팀·팀원 조회 계약 확인 완료(3단계 선행 조건).
- [ ] 실제 WebView 포그라운드 복귀 검증 완료(2단계 검증).

# 회원 웹 배포용 공통 데이터

- 이슈: #399 / 작성일: 2026-11-09 / 상태: 구현 승인
- 대상: 배포 회원 웹과 앱 WebView의 모든 사용자. 실제 인증 권한은 변경하지 않는다.

## 사용자 시나리오와 수용 조건

1. 사용자는 일정에서 이번 주 토요일 기준 14일 후부터 매주 열리는 정규 세션 3개를 확인한다.
2. 홈에는 이번 주 세션 없음이 표시되며 출석 진입이 없다. 직접 제출도 서버로 보내지 않는다.
3. 홈·목록·상세는 같은 두 공지를 표시하며 첫 일정과 날짜·장소가 일치한다.
4. 샘플 표기는 표시하지 않는다. 로그인·회원 정보·출석 내역·점수는 실제 API를 유지한다.
5. 정적 모드를 끄고 재빌드하면 기존 실제 API 동작으로 복구된다.

## 요구사항

- API 오류·빈 응답을 이유로 정적 응답으로 전환하지 않는다. 빌드 설정으로만 선택한다.
- 공지 필터·상세·읽음 처리는 정적 공지 ID 안에서 일관되게 동작한다.
- 읽음 상태는 계정별 메모리에 한정하며 새로고침 시 초기화한다.
- 인증 없는 브라우저도 공개 정적 콘텐츠를 볼 수 있지만 회원 API의 접근 조건은 유지한다.
- 설정이 잘못되면 명시적으로 실패하며 묵시적으로 실제 쓰기를 허용하지 않는다.
- URL 오류 시나리오 파라미터와 Service Worker에 의존하지 않는다.
- 날짜는 앱 문서 초기화 시 계산한다. 재접속하면 상대 날짜도 다시 계산된다.
- 실제 서버 데이터, 앱 네이티브 설정, 공용 API 계약은 변경하지 않는다.

## 성공 기준

생성 SDK를 통과하는 정적 조회·검증, 대상 밖 요청 전달, 출석 전송 차단, production 미리보기와 설정 해제를 검증한다.
심사 통과를 보장하거나 현재 데이터가 서버에 저장되어 있다고 설명하지 않는다.

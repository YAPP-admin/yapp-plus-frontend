## 작업 배경

관리 가능한 기수 목록 API가 추가됐다. 현재 관리자 세션 CRUD는 환경 변수의 기수 ID를 사용하므로
로그인 후 최신 기수를 자동 설정하고 운영진이 기수를 전환할 수 있도록 연결한다.

## 작업 내용

- [ ] 최신 OpenAPI로 생성물을 갱신하고 기존 API 소비자의 호환성을 유지한다.
- [ ] 로그인 후 최신 기수를 선택하고 Context로 공유해 세션 CRUD에 반영한다.
- [ ] 데스크톱·모바일 탐색에서 기수를 바꾸고 화면 이동 중 선택을 유지한다.
- [ ] 빈 목록·조회 실패·인증 오류를 안내하고 기수 미확정 세션 요청을 차단한다.
- [ ] 기수별 요청·모달·캐시를 분리하고 자동 테스트·접근성·운영 문서를 갱신한다.

## 완료 조건

- [ ] 로그인·새로고침·재로그인 시 최신 기수로 시작한다.
- [ ] 기수 전환 후 세션 조회·생성·수정·삭제가 선택한 ID만 사용한다.
- [ ] 늦은 응답이나 이전 계정 데이터가 현재 화면과 섞이지 않는다.
- [ ] check/build와 대표 사용자 흐름 검증 결과를 새 실행·캐시 재사용으로 구분해 기록한다.

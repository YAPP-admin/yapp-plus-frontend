# feature: 홈 세션 카드 정합성과 카카오맵 연결

## 작업 배경

회원 홈의 장소·제목·달력 표시를 안드로이드와 맞추고, 세션 좌표로 카카오맵을 열 수 있게 한다.

## 작업 내용

- [ ] 지도 핀·장소명, 오늘/이번 주 제목, 달력·정규 버튼 스타일을 맞춘다.
- [ ] 카카오맵 앱에서 좌표를 열고 실행 실패 시 웹 지도로 연결한다.
- [ ] 기존 출석 전·마감 안내와 팀 사진 제출·검토·결과 흐름을 유지한다.
- [ ] Spec Kit 문서, 모바일 실행, 웹 연결 순서로 단계별 검토한다.

## 완료 조건

- [ ] 좌표 누락·오류는 지도 링크를 만들지 않고, 일반 브라우저·구버전 셸도 HTTPS 링크를 사용한다.
- [ ] 회귀 테스트·접근성·check·build와 iPhone 설치/미설치·복귀 검증 결과를 기록한다.
- [ ] 새 API·브리지 계약·의존성을 추가하지 않는다.

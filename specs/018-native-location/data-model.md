# 데이터 모델과 수명

공개 필드와 검증의 단일 명세는 [브리지 계약](contracts/location-bridge.md)이다.
데이터베이스·서버 API·마이그레이션은 추가하지 않는다.

| 개체               | 소유자                        | 수명                                                   |
| ------------------ | ----------------------------- | ------------------------------------------------------ |
| LocationPermission | OS에서 조회하는 네이티브 동작 | 호출 시마다 조회하며 웹 공유 상태로 유지하지 않음      |
| LocationSample     | 네이티브 요청 → 웹 호출자     | 한 번의 응답 처리까지만 사용, 영구 저장·캐시·로그 금지 |
| LocationFailure    | 각 실행 경계                  | 정규화된 코드와 필요한 권한 재요청 여부만 전달         |
| 진행 중 요청       | 네이티브 위치 동작            | BUSY 잠금과 측정 응답 대기 타이머를 소유               |

상태 전이는 `idle → permission → measuring → settled → idle`이다.
permission/measuring에서 중복 요청은 BUSY이며 새로운 수집을 만들지 않는다.
권한 선택 대기에는 별도 타이머를 두지 않는다. 권한 미허용·서비스 꺼짐·비활성 상태에서는 측정하지 않는다.
measuring에서 단발 응답·오류·15초 timeout으로 settled가 되고 타이머와 잠금을 해제한다.
OS 측정은 취소하지 않는다. timeout 후 재시도와 겹칠 수 있지만 이전 결과는 새 요청이나 UI에 반영하지 않는다.
웹 화면의 수명 토큰은 별도로 늦은 UI 반영을 막으며 네이티브 취소를 의미하지 않는다.

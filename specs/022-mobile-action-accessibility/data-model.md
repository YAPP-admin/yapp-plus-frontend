# 화면 상태와 수명

새 서버 모델·저장소·마이그레이션은 없다.

| 상태                     | 소유자                        | 수명과 규칙                                                                     |
| ------------------------ | ----------------------------- | ------------------------------------------------------------------------------- |
| 가입 단계 `name / phone` | Signup Activity step params   | 기본 name; 유효한 이름 제출 시 phone step 추가; 뒤로가기는 이전 step            |
| 이름·휴대폰 입력값       | SignupPage의 기존 폼 인스턴스 | 단계 변경으로 재생성하지 않음; Activity 폐기·새로고침 시 초기화                 |
| 입력·서버 필드 오류      | 기존 폼과 페이지 오류 상태    | 서버 name 오류 시 name 단계·포커스; 다른 필드 오류는 해당 입력 수정 전까지 보존 |
| 제출 상태                | 기존 가입 mutation            | 기존 제출 정책 유지; pending 표시 및 중복 요청 차단                             |
| 가시 영역                | 가입 화면 전용 훅             | 활성일 때만 구독; 화면 이탈 시 해제; 확대를 키보드로 해석하지 않음              |
| 본문 스크롤 위치         | 실제 본문 DOM                 | 탭은 마운트를 유지해 복귀 시 보존                                               |

입력 검증은 기존 signupNameSchema·signupPhoneNumberSchema·signupFormSchema를 재사용한다.
이름·휴대폰 값을 URL·step params·문서·캡처에 기록하지 않는다. QA에는 합성 입력만 사용한다.
서버 name 오류로 되돌아갈 때 뒤로가기가 곧바로 오류가 있던 phone으로 복귀하는 새 이력을 만들지 않는다.

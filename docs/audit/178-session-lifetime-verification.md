# 세션 화면 수명과 남은 접근성 검증

발견 ID V04, #178. 지연된 생성·수정 응답 뒤 실행하는 닫기·탐색·알림을 mutation 호출별
성공 콜백으로 옮깁니다. 관찰하던 화면이 해제되면 화면 전용 콜백을 실행하지 않습니다.
저장 자체와 query hook의 데이터 갱신은 유지합니다. 같은 경로에서 필터만 바뀌면 성공 안내는
현재 필터를 기준으로 표시합니다.

새 테스트는 실제 Query mutation에 지연 응답을 주고 화면 해제 후 close·created·snackbar가
실행되지 않는지 확인합니다. 같은 경로의 필터 변경도 확인합니다. 폼 입력과 Snackbar 표시
컴포넌트는 대체하고, 기존 목록·폼 통합 테스트를 함께 실행합니다. 현재 메모리 서비스에
주입한 지연이며 운영 API 장애를 확인한 결과는 아닙니다.

남은 실제 환경 검증은 다음과 같습니다.

- #146 휠 정착 처리 반영 후 터치 관성·키보드·VoiceOver/NVDA의 값·확정 상태 안내.
- #149 원래 trigger가 사라지는 경우의 포커스 정책 결정과 복귀 검증.
- 지도 마커 drag-only 입력의 접근 가능한 대안. 기존 제외 정책을 승인 없이 변경하지 않습니다.
- #151의 동일 문자열·다른 주소 식별자를 실제 공급자 결과로 확인하고 좌표 신원을 대조.
- #152와 함께 초기 조회·저장 지연·저장 후 경로 이동·같은 경로 필터 변경을 브라우저에서 확인.

전체 조건이 끝나지 않았으므로 이 PR은 #178을 닫지 않습니다. 실제 접근성 검증 결과는
기기·브라우저·보조기술 버전·조작·결과를 기록하고 dots의 기존 검증과 분리합니다.

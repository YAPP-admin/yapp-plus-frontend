# 검증 실행 안내

## 준비

고정 Node 24.20.0·pnpm 12.3.4와 기존 의존성을 사용한다. 개발용 API 모의 환경은 저장소의
기존 설정으로 실행하고 운영 계정이나 비밀 값을 문서·화면 증거에 포함하지 않는다.

## 자동 검증

```sh
pnpm --filter @yapp-plus/mobile test src/external-navigation.test.ts
pnpm --filter @yapp-plus/web test src/pages/home/model/session-map.test.ts src/pages/home/ui/home-page.test.tsx
node --run check
node --run build
```

위 테스트 파일은 해당 구현 단계에서 추가한다. 기본 게이트는 단계별 실제 변경에 맞춰 실행하고,
문서만 변경한 1단계에는 build·실기기 검증을 요구하지 않는다. 모바일 설정·의존성을 변경하게 되면
`node --run expo:doctor`도 실행한다. 현재 계획에는 해당 변경이 없다.

## 수용 사례

| 계층        | 사례                                   | 기대 결과                                   |
| ----------- | -------------------------------------- | ------------------------------------------- |
| 웹 모델     | 정상·0·경계·누락·범위 초과·NaN·무한대  | 유효 좌표만 순서대로 HTTPS URL 생성         |
| 모바일 경계 | 앱 성공·앱 실패·HTTPS 실패             | 앱만 실행 / 웹 대체 / 안내                  |
| 모바일 경계 | 유사 호스트·잘못된 경로·일반 외부 링크 | 앱 스킴 오변환 없이 기존 외부 처리          |
| 홈 화면     | 오늘·다른 날·이름 중복·장소 누락·TEAM  | 명세대로 제목·장소 표시                     |
| 홈 화면     | 세션 없음·로딩·오류·출석 상태·팀 검토  | 기존 흐름과 새 표시 공존                    |
| 홈 화면     | 링크 클릭·키보드·긴 장소명·좁은 화면   | 올바른 href·접근성 이름·충돌 없는 터치 영역 |
| iPhone      | 카카오맵 설치·미설치·앱 복귀           | 좌표 일치·웹 대체·홈 탐색 유지              |

브라우저는 `node --run dev:web`로 실행하고 320px·390px 너비와 라이트·다크 테마를 확인한다.
일반 브라우저와 구버전 셸의 HTTPS 동작을 앱 스킴 검증과 구분한다. iPhone VoiceOver·큰 글자도
확인한다. 화면 증거는 `.context/`에 저장하고 검증 기록에서 링크한다.
미실행 기기 사례는 자동 테스트 통과로 대체하지 않는다. 결과는 새 실행과 Turbo 캐시를 구분한다.

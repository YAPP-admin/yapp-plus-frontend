# 화면 데이터와 상태 수명

| 개체               | 원천                           | 소유자·수명                                                  |
| ------------------ | ------------------------------ | ------------------------------------------------------------ |
| 제출 대상·명단     | 개발 fixture, 후속 서버 조회   | Activity 흐름. 계정·대상 변경 시 초기화                      |
| native 처리 파일   | 사용자 선택·촬영               | 처리 runtime. 응답 준비 후 생성 캐시 삭제                    |
| JPEG Blob·미리보기 | 검증된 RPC 또는 브라우저 파일  | 업로드 화면. 교체·이탈 시 URL 해제                           |
| 선택 membershipIds | 본인 기본 선택과 사용자 입력   | 업로드 폼. 본인 포함·명단 부분집합                           |
| 비동기 상태        | mutation                       | 단일 제출 시도. 사진 바이트는 mutation cache에 저장하지 않음 |
| 접수 확인          | 유효한 submit 응답 + 당시 명단 | Activity 흐름. 새로고침·직접 진입 복원 없음                  |

사진 준비 → 팀원 선택 → 제출 중 → 접수 확인으로 이동한다. 취소는 이전 선택으로, 확정 실패는 입력을 유지한 오류 상태로 돌아간다. submit 결과 불명은 재전송 가능한 실패와 구분한다. 검토 대기는 출석 승인이 아니다. 영구 초안·업로드 재개·전역 사진 저장소는 만들지 않는다.

# 기능 명세: 홈 세션 카드 정합성과 카카오맵 연결

**실제 브랜치**: `DongjaJ/dongjaj/keep-current-implementation`
**작성일**: 2026-11-28 · **상태**: 2단계 리뷰 대기
**입력**: 사용자가 승인한 홈 카드 표시 통일·카카오맵 앱 우선 실행 계획.

## 사용자 시나리오와 검증

### US1 — 세션 장소를 지도에서 확인 (P1)

회원은 홈의 지도 핀이나 장소명을 눌러 세션 장소를 확인한다.
장소를 다시 검색하지 않고 이동 준비를 할 수 있으므로 우선한다.
독립 검증: 같은 좌표의 지도 링크를 앱 설치·미설치 환경에서 열어 목적지를 확인한다.

1. 유효한 세션 좌표와 카카오맵 설치 상태에서 장소를 누르면 해당 좌표 중심의 지도가 열린다.
2. 카카오맵을 실행할 수 없으면 같은 좌표의 웹 지도가 열린다.
3. 좌표가 없거나 잘못되면 장소 안내만 보이고 지도 이동은 제공하지 않는다.
4. 웹 지도도 열 수 없으면 다시 시도할 수 있는 안내를 표시하고 홈을 유지한다.

### US2 — 안드로이드와 일관된 홈 카드 확인 (P2)

회원은 세션 장소·오늘 여부·예정일·출석 완료를 카드에서 구분한다.
독립 검증: 고정 날짜·세션 상태를 공급해 제목·장소·달력과 버튼을 비교한다.

1. 세션 당일에는 “오늘은 … 세션이에요”, 다른 날에는 “이번 주는 … 세션이에요”를 표시한다.
2. 이름 끝에 “세션”이 있어도 제목에 중복하지 않는다.
3. 정규 장소가 비어 있으면 “장소 미정”, 팀 세션이면 “팀별 자율 장소”를 표시한다.
4. 오늘·세션 예정일·출석 완료를 구분하되 기존 출석 전·마감 안내 문구와 시점은 유지한다.

### 경계 사례

- 좌표의 일부 누락·범위 초과·유한하지 않은 값은 지도 이동을 만들지 않는다. 숫자 0은 유효하다.
- 긴 장소명은 좁은 화면에서도 읽을 수 있고, 링크와 제목의 터치 영역이 겹치지 않는다.
- 세션 없음·로딩·조회 오류는 기존 흐름을 유지하며 지도 링크를 노출하지 않는다.
- 지도에서 복귀해도 홈 탐색 상태와 기존 재조회 동작을 유지한다.

## 요구사항

### 기능 요구사항

- **FR-001**: 장소 앞에 14px 지도 핀을 표시하고 유효한 좌표가 있을 때만 장소 행을 링크로 제공한다.
- **FR-002**: 카카오맵 앱 실행을 우선하고 실패하면 웹 지도로 연결한다. 일반 브라우저는 웹 링크를 사용한다.
- **FR-003**: 지도는 세션 좌표를 표시한다. 현재 위치 권한이나 길찾기를 요청하지 않는다.
- **FR-004**: 한국 시간 기준 오늘 여부를 제목에 반영하고 이름 끝의 “세션” 중복을 제거한다.
- **FR-005**: 정규 카드의 별도 시작 시간 줄을 제거하되 기존 출석 버튼의 안내·활성 조건을 유지한다.
- **FR-006**: 달력 예정일 강조색·구분선·간격과 정규 출석 버튼의 상태별 스타일을 안드로이드 기준에 맞춘다.
- **FR-007**: 팀 사진 제출·검토 영역·결과 모달을 유지한다. 사진 보기·결과 확인 버튼은 추가하지 않는다.
- **FR-008**: 장소 링크는 키보드·스크린 리더·터치로 조작할 수 있고 목적지를 설명하는 이름을 제공한다.
- **FR-009**: 기존 출석 전 20분 안내·마감 안내·출석 정책과 최신 main의 로딩 화면을 유지한다.

### 핵심 정보

- 세션: 기존 이름·유형·일정·출석 상태와 장소·좌표를 읽는다. 저장 정보를 변경하지 않는다.
- 지도 목적지: 검증된 세션 좌표 하나를 사용하며 사용자 위치는 수집하지 않는다.

## 성공 기준

- **SC-001**: 카카오맵 설치·미설치 수용 사례에서 장소 행을 한 번 눌러 같은 세션 좌표를 확인한다.
- **SC-002**: 좌표 누락·오류 사례에서는 잘못된 지도 이동이 한 번도 발생하지 않는다.
- **SC-003**: 오늘/다른 날짜·장소 누락·예정일·출석 완료 사례가 정한 표시와 모두 일치한다.
- **SC-004**: 기존 출석 안내와 팀 사진 흐름의 회귀 사례가 통과하고 키보드·터치 조작을 확인한다.

## 가정과 범위

- 대상은 회원 웹과 이 저장소의 iOS 셸이다. 별도 Android 저장소를 수정하지 않는다.
- 비교 기준은 Android `8cbf4b83ff8e676cef1ab6ea5cb3f8b321f23f43`이다.
- 팀 세션 좌표는 기존 계약상 없지만 표시·링크 판정은 좌표의 유효성으로 결정한다.
- 일반 브라우저와 구버전 iOS 셸은 HTTPS 링크로 동작하며 앱 자동 전환을 보장하지 않는다.
- 작업 이슈는 [#665](https://github.com/YAPP-admin/yapp-plus-frontend/issues/665)다. 후속 구현은 단계별 리뷰 뒤 진행한다.

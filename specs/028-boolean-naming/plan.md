# 구현 계획: 불리언 명명 정리

## 기술 맥락

- 대상: `apps/admin`, `apps/mobile`, `apps/web`, `packages/*`의 TypeScript/TSX 내부 코드
- 기준: [감사 보고서](../../.context/boolean-naming-audit.md), 이슈 #504
- 제외: 생성 코드, API enum·상태 리터럴, 공개 export와 React hook의 이름 변경

## 단계

1. 각 앱의 지역 상태 변수와 순수 비공개 질의를 술어형으로 변경하고 인접 테스트를 갱신한다.
2. 반환값을 제어 흐름에 사용하는 조건부 명령은 호출부와 함께 `try…` 또는 `…IfNew` 의미로 변경한다.
3. 공개 export 후보와 테스트 전용 후보는 호출 영향·PR 크기를 검토해 별도 작업으로 남긴다.
4. 변경 앱별 검사 후 전체 `node --run check`를 실행한다.

## 헌법 점검

- 최소 범위: 실제 내부 소비자만 변경하며 새 의존성·추상화를 추가하지 않는다.
- 계약: 생성 코드와 외부 API를 변경하지 않는다.
- 검증: 이름 변경으로 영향을 받는 호출부·테스트를 같은 변경 단위에서 확인한다.
- Git: 앱별로 검토 가능한 PR로 나누고 800줄 미만을 유지한다.

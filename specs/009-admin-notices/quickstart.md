# 구현 후 검증 안내

4a와 기본 툴바 구현을 검토했다. 2026-10-23 사용자 결정으로 현재 편집기를 유지하고, 남은 입력·접근성 검증과 고도화는 후속 작업으로 보류한다. 아래 종합 시나리오는 아직 모두 실행하지 않았다.

## 실행 준비

- 저장소의 mise 고정 도구를 사용한다. 의존성이 없으면 `mise exec -- pnpm install --frozen-lockfile`로 설치한다.
- 개발 화면: `mise exec -- pnpm --filter @yapp-plus/admin dev` 실행 후 출력 주소의 /notices로 이동한다.
- 단위·UI 테스트: `mise exec -- pnpm --filter @yapp-plus/admin test`.
- 품질 게이트: `mise exec -- node --run check`, 앱·빌드 변경 후 `mise exec -- node --run build`.
- 프로덕션 확인: 빌드 후 `mise exec -- pnpm --filter @yapp-plus/admin start`로 공지 경로의 준비 중 안내를 확인한다.
- admin Storybook 실행 명령은 11a 설정 시 이 문서에 추가한다. 현재 존재하는 명령으로 오인하지 않는다.

## 3단계 검증 기록 — 2026-10-19

- Tiptap core/react/pm/starter-kit/markdown을 catalog 3.32.0으로 고정했다.
- `pnpm install --frozen-lockfile`, `node --run check`, `node --run build`를 mise 고정 도구로 실행해 통과했다.
- React 19.2.8에서 StarterKit·Markdown·useEditor를 함께 로드하고 immediatelyRender:false로 서버 렌더링을 확인했다.
- pnpm 공급망 검사를 통과했다. peer 경고는 기존 모바일 expo-modules-core와 react-native-worklets의 범위 불일치이며 변경하지 않았다.
- 의존성 3개 파일의 변경은 추가 526줄이다. 앞선 문서 PR과 분리해야 하며 아직 commit·PR은 생성하지 않았다.
- 기능 UI·Markdown 왕복·한글 입력 검증은 4단계 이후에 수행한다. 앱 화면 변경과 스크린샷은 없다.

## 4a단계 검증 기록 — 2026-10-20

- 사용자 요청에 따라 저장 포맷을 JSON으로 변경하고 Markdown 패키지를 Placeholder 3.32.0으로 교체했다.
- JSON 왕복·빈 본문·노드/버전/링크 검증·SSR·초기값·key 초기화·Placeholder 표시와 비저장 등 13개 테스트를 통과했다.
- 새 에디터는 예시 없이 빈 문단으로 시작한다. 툴바·화면 연결·실제 브라우저 한글 입력과 접근성 검증은 후속 단계다.
- 후속 PR의 base는 Tiptap 의존성 커밋 f61de2f로 잡는다. 기존 의존성 PR에 합쳐 크기 제한을 넘기지 않는다.

## 툴바 개발용 확인 — 2026-10-20

- /notices/new의 개발 환경에서 빈 에디터를 직접 입력할 수 있도록 연결했다. 저장 기능은 아직 연결하지 않았다.
- 현재 툴바 버튼은 H1~H6·굵게·링크·글머리 목록·인라인 코드다. 번호 목록·코드 블록은 확장 기능으로 지원하며 실행 취소/다시 실행은 키보드로 사용한다.
- Chrome에서 직접 입력·굵게 선택 상태·H2 변경·실행 취소/다시 실행을 확인했다. 화면은 .context/notice-editor-empty.png에 기록했다.
- 실제 한글 IME 조합·375px·스크린 리더·터치 및 Storybook 검증은 남아 있다.

## 현재 구현 기준 정리 — 2026-10-23

- 이전 4a 검증 기록의 13개 테스트는 당시 구현에 대한 기록이다. 현재 테스트는 편집기 4개와 확장 1개이며, 저장 경계의 JSON·빈 본문 검증은 5a에서 구현한다.
- 4b의 남은 한글 IME·붙여넣기·접근성 수동 검증은 보류하며 통과로 간주하지 않는다. 사용자 승인으로 5a 데이터 기반 단계로 진행한다.

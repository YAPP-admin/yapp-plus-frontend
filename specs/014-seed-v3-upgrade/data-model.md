# 계약 모델: SEED React 3 업그레이드

이 변경은 제품 데이터나 영속 스키마를 바꾸지 않습니다. 아래는 구현과 검증에서 추적할 의존성·UI 계약 상태입니다.

## 의존성 집합

| 항목             | 목표 상태 | 제약                                      |
| ---------------- | --------- | ----------------------------------------- |
| SEED React       | `3.1.0`   | CSS `^3.1.0` peer와 함께 설치             |
| SEED CSS         | `3.1.0`   | 모든 앱과 UI 패키지가 catalog 사용        |
| SEED Vite plugin | `2.1.1`   | CSS 3 peer 지원                           |
| SEED CLI         | `1.7.3`   | 실행할 때만 고정 사용                     |
| `clsx`           | `2.1.1`   | `packages/ui`의 Time Picker 런타임 의존성 |

## 공용 UI 계약

| 공개 항목      | 상태      | 불변 조건                            |
| -------------- | --------- | ------------------------------------ |
| `ActionButton` | 갱신      | 기존 호출 API와 ref 전달 유지        |
| `Badge`        | 신규 공개 | snippet의 현재 props만 노출          |
| `DatePicker`   | 신규 공개 | 현재 일정 선택에 필요한 props만 노출 |
| `TimePicker`   | 신규 공개 | 현재 일정 선택에 필요한 props만 노출 |
| `WheelPicker`  | 내부      | 공개 진입점에서 export하지 않음      |

## 마이그레이션 상태

```text
v2 기준 상태
  → 의존성·snippet 정렬
  → 공용 계약 갱신
  → 앱 사용처 이동
  → 자동·수동 검증 완료
  → v3 완료 상태
```

각 단계 사이의 혼합 상태는 배포하지 않습니다. 검증에 실패하면 같은 변경 단위에서 v2 기준 상태로 되돌립니다.

## 검증 불변 조건

- Alert Dialog의 역할과 바깥 클릭 정책이 유지됩니다.
- 일정 선택의 초안과 확정값이 분리되고 취소·Escape 동작이 유지됩니다.
- 첨부 파일의 정상·거절 결과가 기존과 같습니다.
- 필터의 선택값과 키보드 조작이 유지됩니다.
- `layerFill` 사용처가 0건이고 `neutralMuted`가 동일한 표면 의미를 가집니다.
- 제품 데이터 migration은 없습니다.

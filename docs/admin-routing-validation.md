# 관리자 라우팅 PR 1 검증

- 확인일: 2026-10-11.
- 관련 이슈: [#46](https://github.com/YAPP-admin/yapp-plus-frontend/issues/46).
- 범위: 공통 셸 분리, 현재 메뉴·키보드 포커스, 404 안내와 복귀, 라우팅 계약 문서화.
- 후속 업무 라우트·쿼리는 구현하지 않았다.

## 자동 검증

- `mise exec -- node --run check`: 통과. 포맷·lint·타입 검사·전체 테스트를 실행했다.
- `mise exec -- node --run build`: 통과. 관리자 빌드는 새로 실행했고 다른 앱은 Turbo 캐시를 사용했다.
- 관리자 테스트: 5개 파일, 19개 테스트 통과. 기존 12개와 새 라우팅 테스트 7개를 포함한다.
- 구현 전 새 404 테스트 4개가 실패하는 것을 확인했고 구현 후 모두 통과했다.
- 실제 라우트 트리의 대시보드·로그인 분리, 잘못된 경로 3개, 키보드 복귀와 클라이언트 이동을 확인했다.
- 테스트에서는 HTML 문서 셸만 교체한다. 실제 문서 렌더링과 HTTP 상태는 빌드 서버에서 확인했다.
- Node.js 24.20.0, pnpm 12.3.4를 사용했다. mise 설정은 해당 실행에만
  `MISE_TRUSTED_CONFIG_PATHS`로 신뢰 범위를 지정했다.

## 서버와 브라우저

- 프로덕션 서버에서 `/`, `/login`은 HTTP 200과 기존 화면 내용을 반환했다.
- `/missing`, `/login/missing`, `/sessions/not-yet-available`은 HTTP 404와 안내·복귀 링크를 반환했다.
- Chrome에서 대시보드·로그인·404를 직접 열고 새로고침 및 복귀를 확인했다.
- 375px와 1280px 폭에서 세 화면 모두 가로 넘침이 없었다.
- 대시보드 메뉴는 `aria-current="page"`와 밑줄을 제공한다. 브랜드·메뉴의 키보드 순서를 확인했다.
- 404 링크는 Tab으로 포커스되고 2px 포커스 테두리를 표시하며 Enter로 대시보드에 복귀했다.
- 메뉴와 복귀 링크의 최소 높이는 44px이다. 로그인에는 관리자 메뉴가 표시되지 않는다.

## 남은 확인과 참고

- 실기기 터치·VoiceOver 음성 출력·다크 모드는 직접 검증하지 않았다. 의미 구조와 접근성 속성은
  테스트 및 브라우저 DOM에서 확인했다.
- 개발 서버의 기존 `LoginRoute` export에 대한 코드 분할 경고가 남아 있다. 해당 export는 변경하지 않았다.
- 전체 빌드 로그에는 기존 Storybook 청크 크기 경고가 포함되며 빌드는 성공했다.
- 사용자 승인 전에는 PR 2 세션 목록 단계에 착수하지 않는다.

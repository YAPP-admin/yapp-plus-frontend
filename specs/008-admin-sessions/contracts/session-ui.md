# 세션 UI와 URL 계약

## 라우트와 공개 진입점

- 기존 `/sessions`를 유지한다. 검색값은 `type=regular|team`이며 전체는 생략한다.
- `type` 누락·잘못된 값과 예전 `part`만 있는 URL은 전체로 해석한다.
- `type`과 `part`가 함께 있으면 유효한 type만 사용한다. 필터 탐색 시 type만 기록한다.
- 초기 방문 시 강제 redirect를 추가하지 않는다. 필터 변경은 history에 기록하고 스크롤을 리셋하지 않는다.
- 페이지는 type과 필터 변경 콜백을 받는다. 내부 데이터 함수는 라우트에서 직접 호출하지 않는다.
- 목록은 1열로 표시하고 카드 본문은 비대화형 정보 영역으로 둔다. 출석부 링크·이동 화살표·클릭을 암시하는 호버 효과를 제공하지 않는다. 수정·삭제는 케밥 메뉴로 실행한다. 기존 출석 관리 화면의 이동 동작은 변경하지 않는다.

## 상호작용

- 생성 버튼은 목록과 전체 빈 상태에서 제공한다. 필터 빈 상태에서는 전체 보기와 기존 생성 버튼을 이용한다.
- 메뉴에는 연결이 완료된 작업만 노출한다. 수정·삭제 기능은 각각 구현 단계에서 활성화한다.
- 모달 열기는 해당 트리거를 기억한다. 생성은 명시적인 label이 있는 필드와 저장·취소 버튼을 제공한다.
- Enter는 폼을 제출한다. 첫 제출 전 오류를 노출하지 않고 이후 입력 변경 시 재검증한다.
- 생성·수정·삭제 실패는 모달 안에서 안내한다. 생성 성공은 SEED Snackbar로 알린다.
- 삭제 확인 문구는 세션명을 표시하고 관련 출석 기록도 삭제된다는 정책을 안내하되 실제 연동은 후속 범위다.
- 이미 사라진 id에 대한 작업은 성공을 가장하지 않고 오류와 목록 새로고침 경로를 제공한다.
- 프로덕션에서는 준비 중 안내만 제공하고 모의 데이터·편집 버튼을 노출하지 않는다.

## 수정 폼

- 메뉴 이름은 `세션 정보`를 유지하고 폼 제목은 `세션 수정`, 제출 버튼은 `저장`으로 표시한다.
- 열 때 마지막 저장값으로 초기화하고 편집 중인 값은 목록 캐시와 분리한다. 다른 세션을 열면 이전 편집값을 재사용하지 않는다.
- 생성과 같은 검증·제출 중 잠금·실패 입력 보존을 적용한다. 취소 시 저장하지 않고 별도 폐기 확인창 없이 닫는다.
- 수정 성공 시 현재 필터를 유지한다. 유형·날짜 변경을 필터와 정렬에 반영하고 id·출석 집계는 보존한다.
- 수정 대상이 사라졌다면 오류를 안내하고 목록을 새로고침할 수 있게 한다. 임의로 생성하지 않는다.
- 저장에 성공한 뒤 실행한 카드가 필터에서 사라졌다면 남은 카드 또는 목록 제목으로 포커스를 이동한다.
- 수정 시 알림 발송이나 출석 재계산을 수행하지 않는다.

## 테스트 경계

페이지 테스트는 service 모듈을 대체하여 지연·실패·빈 결과를 재현한다.
서비스 자체 테스트는 독립 저장소로 생성·조회·수정·삭제·복사본 분리를 검증한다.
UI에서 새로운 테스트 전용 URL, debug 전역 변수 또는 mock 제어 패널은 제공하지 않는다.

## 빈 상태 CTA 정책 (8단계 리뷰 반영)

- 전체 필터의 빈 목록은 중앙 패널에 제목·설명·`세션 만들기` CTA를 표시한다.
- 생성 CTA는 개발 환경에서 활성화하며 상단 생성 버튼과 같은 폼을 연다. 8단계의 비활성·준비 중 안내는 11단계 연결로 대체한다.
- 필터 선택 중 빈 목록은 전체 데이터 유무에 관계없이 `필터 초기화` CTA를 제공한다. 기존 URL 필터 변경 경로로 전체 목록을 표시하고 뒤로 가기 이력을 유지한다.

## 생성 폼 입력과 공통 안내

- 같은 페이지에서 생성 모달을 닫고 다시 열면 입력을 유지한다. 생성 성공 콜백에서만 form.reset()을 호출해 입력을 초기화한다. 페이지 이탈·새로고침까지 초안을 보존하지 않는다.
- Snackbar Provider와 표시 영역은 루트 라우트의 Providers에 둔다.
- 모달 포커스 복귀는 SEED의 기본 동작을 사용하며 생성 후 빈 목록 CTA가 사라지는 경우 별도 보정을 하지 않는다.

### 날짜·시간 선택기

- 날짜는 SEED DatePicker, 시작·종료 시간은 SEED TimePicker를 별도의 SEED Dialog에서 선택한다.
- 날짜와 시간은 SEED FieldButton을 눌러 선택하며, 선택한 값을 버튼에 표시한다. 직접 텍스트 입력은 제공하지 않는다. 날짜는 `YYYY-MM-DD`, 시간은 `HH:mm`으로 검증·저장한다.
- 시간 휠은 오전·오후를 표시하고 1분 단위로 선택한다. 기존 입력을 임의로 반올림하지 않는다.
- 다이얼로그 진입 애니메이션은 SEED 기본값을 유지한다.

- 선택 Dialog는 열 때 기존 값으로 임시 값을 준비하고, 확인할 때만 폼에 반영한다. 시간의 최초 선택 값은 `00:00`이다.
- 취소·Esc·바깥 클릭은 임시 변경을 버린다. 닫으면 기존 생성 Dialog를 유지하고 선택을 시작한 FieldButton으로 포커스가 돌아간다.

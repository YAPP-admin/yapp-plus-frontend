# 공통 HTTP 오류 계약

- 기준: origin/main c41d6160. 관련 이슈: #160. 사진 작업과 독립된 PR이다.
- 생성 Query/Mutation이 실패해도 HTTP 상태와 오류 본문을 ApiError로 확인할 수 있어야 한다.
- JSON·텍스트·빈 오류 본문을 한 번만 읽고, throwOnError false의 response와 error도 보존한다.
- 네트워크·취소 예외는 HTTP 오류로 바꾸지 않는다. 요청·토큰·URL은 ApiError에 보관하지 않는다.
- 모든 앱은 공통 초기화를 사용하고, 기존 오류 코드 분기·인증 갱신을 유지한다.
- 최신 공개 OpenAPI로 재생성하되 추가된 계약만 반영한다. 새 기능 UI는 구현하지 않는다.
- 공용 설정과 소비자 변경을 함께 되돌리면 기존 동작으로 복구할 수 있다. 배포는 범위 밖이다.

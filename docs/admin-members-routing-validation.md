# 관리자 라우팅 PR 4 검증

- 확인일: 2026-10-11. 관련 이슈: [#53](https://github.com/YAPP-admin/yapp-plus-frontend/issues/53).
- 기준 커밋: PR 3 `66bbb95`. 브랜치: `DongjaJ/admin-members-routing`.
- 범위: `/members`, 회원 관리 메뉴, 전체 회원·가입 대기 구분, 이름 검색, 직군·권한·상태 필터.
- 실제 회원 데이터·API·인증·회원 수정·가입 승인/거절·명단 업로드는 포함하지 않는다.

## URL과 검색 동작

- `tab`: `all | pending`. `part`: `all | pm | design | android | ios | web | server`.
- `role`: `all | admin | active-member | regular-member`. `status`: `all | active | inactive`.
- 이름 검색 `q`는 문자열이고 기본값은 빈 문자열이다. 나머지 기본값은 `all`이다.
- 잘못된 외부 입력은 필드별 기본값으로 처리하고 앱이 만드는 URL에서는 기본값을 생략한다.
- 탭·선택형 필터는 다른 조건을 보존하며 history에 추가하고 스크롤을 유지한다.
- 이름 검색은 Enter 또는 검색 버튼으로 제출할 때만 URL을 replace한다. 입력 중에는 URL을 바꾸지 않는다.
- 폼 제출 시 FormData에서 문자열을 읽고 최신 URL의 다른 필터는 유지한다.
- URL의 검색 조건이 바뀌면 미제출 입력은 버리고 URL의 검색어로 폼을 초기화한다.
- debounce·타이머·라우터 이벤트 구독·별도 한글 조합 처리는 사용하지 않는다.
- 다른 메뉴로 이동할 때 회원 쿼리를 넘기지 않고 회원 메뉴로 재진입하면 기본 상태를 사용한다.
- 탭 모양의 구분은 URL을 이동하는 링크이며 현재 항목을 `aria-current`로 표시한다.

## 자동 검증

- `mise exec -- node --run check`: 포맷·lint·타입 검사·전체 테스트 통과.
- `mise exec -- node --run build`: 전체 빌드 통과.
- 관리자 테스트 8개 파일, 99개 통과. PR 3 대비 18개를 추가했다.
- 스키마 허용값·누락·잘못된 입력과 복합 필터 복원, Enter·버튼 제출, 검색 replace와 빈 값 생략,
  미제출 입력의 필터 변경·history 복원·페이지 이탈·새 검색 URL 이동을 검증했다.
- 기존 메뉴의 키보드 탐색 테스트는 추가된 회원 메뉴를 포함하도록 갱신했다.
- 생성 라우트는 Vite로 갱신했으며 새 의존성은 추가하지 않았다.
- Node.js 24.20.0, pnpm 12.3.4를 사용하고 mise 신뢰 설정은 실행 명령에만 적용했다.

## 서버와 브라우저

- 프로덕션 서버의 기본·복합·잘못된 쿼리 `/members`는 HTTP 200과 예상 필터를 반환했다.
- `/members/missing`은 HTTP 404를 반환했다.
- Chrome에서 한글 검색 문자열·직군 변경·새로고침 복원·탭 이동을 확인했다.
- 375px와 1280px에서 가로 넘침이 없으며 입력과 필터는 글자 16px, 높이 44px이다.
- 키보드 Enter로 탭을 전환하고 Tab으로 이름 검색에 접근할 수 있다. 2px 포커스 테두리를 확인했다.

## 남은 확인

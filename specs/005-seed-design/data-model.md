# 상태 모델: 시스템 테마

**관련 명세**: [spec.md](./spec.md), US3 / FR-005·FR-006

이번 기능은 영속 데이터, API 스키마와 저장소 마이그레이션을 추가하지 않는다.

## 브라우저 문서별 상태

| 상태           | 값                             | 소유자·수명                                      |
| -------------- | ------------------------------ | ------------------------------------------------ |
| 테마 정책      | `system`                       | 각 앱 HTML, 문서 수명 동안 고정                  |
| 유효 색상 모드 | `light` 또는 `dark`            | 문서 HTML 속성, 시스템 설정 변경 시 갱신         |
| 시스템 관찰자  | `MediaQueryList`와 변경 리스너 | 초기화 스크립트의 지역 상태, 문서 수명 동안 유지 |

## 상태 전이

1. SSR 또는 정적 HTML의 기본 색상은 `light`다.
2. head 스크립트가 dark 미디어 쿼리를 평가해 `dark` 또는 `light`를 적용한다.
3. `change` 이벤트마다 현재 matches 값으로 다시 결정한다.
4. 감지 기능이 없거나 실패하면 `light`를 유지한다.
5. 구형 환경은 `addListener`를 사용한다. 구독 API가 없으면 최초 감지 결과만 적용한다.

값은 스크립트 내부에서 두 리터럴로 결정하며 사용자 입력, 저장소 값이나 URL 값으로부터 읽지 않는다.
테마는 문서별로 독립적이고 Storybook은 preview iframe에 적용한다. 문서당 스크립트는 한 번 배치하고
클라이언트 라우트 이동마다 리스너를 재등록하지 않는다.

## 기타 UI 상태

ActionButton의 `loading`과 `disabled`는 소비자가 전달하는 독립된 props다. 별도의 전역 상태나
비동기 작업 관리 계층을 만들지 않는다. `loading`만으로 클릭을 차단하지 않는다.

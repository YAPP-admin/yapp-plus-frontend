## 남은 수동 검증과 범위 제한

- 실제 터치 기기의 휠 조작·스크롤과 VoiceOver 등 실제 스크린 리더의 음성 안내는 미검증이다. DOM 접근성 이름과 키보드 검증을 이를 대신한 완료로 간주하지 않는다.
- 많은 세션을 생성한 브라우저 부하·성능 검증은 미실행이다. 서버 페이지네이션·추가 로딩은 현재 범위가 아니다.
- 생성·수정·삭제 실패는 서비스 테스트 대역에서 재현했으며 실제 서버 장애는 검증하지 않았다.
- 실제 API, 출석 기록 연쇄 삭제, 점수 재계산, 알림·지도는 구현 범위 밖이다.
- 모달 종료 후 별도 포커스 보정은 사용자 리뷰에 따라 제거했다. 카드가 사라진 경우 목록 제목으로 강제 이동하지 않는다.

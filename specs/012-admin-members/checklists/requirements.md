# 회원 관리 화면 요구사항 체크리스트

**대상**: [spec.md](../spec.md) | **작성일**: 2026-10-29

- [x] 제품 맥락·대상 운영진과 이번 개발 화면 범위를 구분했다.
- [x] 사용자 시나리오별 우선순위·독립 검증·수용 기준을 작성했다.
- [x] 요구사항은 검증 가능하며 구현 기술은 계획·계약 문서로 분리했다.
- [x] 지정된 Figma 8개 링크와 적용·제외 요소를 연결했다.
- [x] 행 목록·사이드바·팀 표시·가입 대기 빈 화면 선택을 반영했다.
- [x] 비활동·기수 정정/추가·덮어쓰기·첫 시트·전화번호·내부 중복 정책을 반영했다.
- [x] 별도 모의 저장소를 제거하고 읽기 전용 fixture와 후속 Faker/MSW 연결을 구분했다.
- [x] 저장·비활동·반영 비활성, 성공 오인 방지, 민감 정보와 환경 경계를 명시했다.
- [x] 오류·빈 상태·파일 경합·접근성과 성공 기준을 작성했다.
- [x] 이번 범위에 미해결 요구사항 표식이 없고 미정 API 계약은 후속으로 분리했다.

체크는 문서의 완결성 평가이며 제품 구현·테스트 통과 또는 사용자 리뷰 승인을 의미하지 않는다.

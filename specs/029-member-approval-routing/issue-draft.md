## 작업 배경

회원 앱의 승인 대기 화면은 있으나 실제 로그인·가입 결과와 연결되지 않았습니다.
로그인 응답의 user.reviewStatus로 서비스 진입을 구분하고 기존 화면과 자동 로그인 정책을 연결합니다.

## 작업 내용

- [ ] 로그인·가입의 승인·대기·거절·확인 불가 상태에 맞는 화면을 표시합니다.
- [ ] 새 대기·거절 계정의 자동 로그인 정보를 저장하지 않고 보호 화면 진입을 차단합니다.
- [ ] 대기 화면에 버튼을 추가하지 않고 기존 뒤로가기 확인 후 로그인으로 복귀합니다.
- [ ] 같은 앱 실행 중 같은 대기 계정이 승인되면 가입 완료 화면을 한 번 표시합니다.
- [ ] 기존 저장 세션 복원을 유지하고 구버전 응답의 필수 필드 누락 거부를 검증합니다.
- [ ] 명세·계약·웹·native·통합 검증을 단계별 리뷰합니다.

## 완료 조건

- [ ] 상태별 이동·직접 진입 차단·계정 전환·정리 실패 회귀 검증이 통과합니다.
- [ ] 대기 중 앱 완전 종료 후에는 로그인하며 백그라운드 복귀는 대기를 유지합니다.
- [ ] check·build 및 실기기 결과를 신규 실행·캐시 재사용·미실행으로 구분해 기록합니다.
- [ ] 기존 세션의 승인 미검사 예외와 OTA 적용 전 로그인 실패 허용을 명시합니다.
